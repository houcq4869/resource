### 竞争力构建方向

**1、工程互操作分架构分层（不造专用 IDE）**
- 介绍：不需要自研 IDE，只需一条命令把 LiteOS 工程生成成 Keil / IAR / VS Code 的原生工程，让传统 MCU 团队"不换工具就能上手、编译、烧录、调试"。Arm 走 CMSIS 标准路线，RISC-V 走 CMake/Ninja 路线，两条线同源派生、保持一致。

**2、Windows 原生 + 最小源码集产品化**
- 介绍：目标是"**纯净 Windows 30 分钟点灯**"。提供一键安装包（自带工具链，支持离线/内网），并提供"最小源码集"（只需内核 + 必需组件 + 单板配置，几百 MB 级），不再强迫用户下载 70GB 全量代码。

**3、双构建后端 + 调试/观测"开墙"**
- 介绍：保留 GN/Ninja 作为与鸿蒙对齐的标准构建，另用 CMake 做轻量兜底（不手写 Makefile，避免两套构建漂移）；同时把已有的内核观测能力接向 GDB、Perfetto 等业界工具，让"能力最强"变成"真正好用"。
