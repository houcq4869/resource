## 1. 构建机制关键结论（影响所有裁剪动作）

1. **config.json 只决定顶层组件目标**（`build/lite/lite_target_list.gni:68-71`）；**GN 传递依赖不受 config.json 控制**——保留组件 BUILD.gn deps 指向被裁目录内目标时，该目标仍被编译。**"从 config.json 删除 ≠ 从镜像删除"**。裁剪分两个口径：组件级（删条目，目录保留）与物理级（删目录，需先断所有 GN 引用）。
2. **xts 默认不构建**：`build_xts` 默认 false（`build/lite/lite_target_list.gni:28`），量产镜像本就不含 acts/tools；config.json 条目删除属账面清理。CI 若跑 debug+test 构建需同步摘除相关套件（global_lite/security_lite PMS 等）。
3. **init cfg 有两份都要改**：`init_liteos_a_3516dv300.cfg` 与 `init_liteos_a_3516dv300_mksh.cfg`（`init_configs/BUILD.gn:15-25`）；残留 start 条目会导致 init 反复 execv 失败 + 240s 退避重启日志噪声（`init_service.c:97-99`），不阻塞启动但污染日志。
4. **release 构建前提下**部分条件项才成立（ui_lite 的 camera_lite test 依赖仅 debug 生效）。

## 3. 修订后的裁剪执行清单

### 第一批（立即执行，低风险）——9 项
config.json 删除：camera_sample_app、camera_screensaver_app、drivers_peripheral_light、device_auth、device_security_level、acts、tools、syscap_codec、device_attest_lite（仓库留树）；
配套：enable_screensaver=false（powermgr/battery features 行删除）；init cfg×2 删除 wms_server 之外本批相关条目（deviceauth_service、dslm_server、devattest_service、sensor_service[若同批]）及 /storage 目录创建行。

### 第二批（条件动作完成后执行）——软总线族 + UI 族 + 按需族
- 同裁组：dsoftbus + dmsfwk_lite（safwk flag + ability 补丁 2 文件）（device_auth/dslm 已随第一批）；
- UI 组：window_manager_lite（条件已随第一批 screensaver off）、ui_lite（ability flag 处置后 + release 构建）、ace_engine_lite（组件级）；
- 按需组：appspawn（组件删/仓库留）、bundle_daemon（仅 init cfg 不启动 + **轮询线程补丁**）、huks_server（延迟至 post-init）、sensor 族（无 PIR 机型）、drivers_peripheral_display/usb/vibrator（条目级）；
- 内核侧音频（保守路线）：LOSCFG_DRIVERS_HDF_AUDIO* 关闭 + hcs audio host 删除（用户态保留空转）。

### 转保留（本轮不裁，阻塞项）——7 项
surface_lite、graphic_utils_lite、ability_lite、i18n_lite、resource_management_lite、permission_lite、audio_lite（用户态）。
**二期攻坚选项**（如需进一步小型化，逐项均为源码级补丁工程）：media_lite 音频手术（顺带解 audio_lite）、ability 族解耦补丁（appspawn AbilityMain 桩化 + BMS want/AMS 解耦，顺带解 ability_lite/dmsfwk/i18n[ace 模块删减]）、camera/media 缓冲通道重构（解 surface/graphic_utils，代价最高不建议）。

### 收益修正说明
阶段 3 §4.4 预估按声明值口径 RAM ~55MB/ROM ~12MB；核查后修正：
- **dsoftbus 族照裁**（最大 RAM 项保留在裁剪集内 ✓）；
- UI 族实际收益缩水：surface/graphic_utils 转保留，ace/ui/wms 为组件级裁剪（目录留树，镜像收益=其二进制产物不再链入，js builtin 死库待二期清理）；
- audio 用户态转保留（一期仅内核侧收益：HDF audio 驱动 + hcs 节点 + 板级 audio_drivers 不编）；
- 新增功耗注意项：**bundlems 200ms 轮询线程**（补丁前为常驻微小唤醒源）。
精确收益以第一批+第二批实施后**构建产物 size 与运行时内存水位实测**为准（PoC T6 计量项）。
