## 6. 死胡同 / 工具限制（如实记录）

1. **`gitee.com/openharmony/openharmony` 不存在**（无 monorepo，无需 fallback 到 web tree）。
2. **`gitcode.com/openharmony/openharmony` 不存在**（403 + `CH.00905403`）。
3. **`kernel_linux_6.12` / `kernel_linux_6.1` / `kernel_linux_5.15` 不存在**；不要臆造 6.12 作为“6.6 后继”。
4. **`vendor_hi3516dv300` / `device_board_hi3516dv300` 不存在**；正确命名是 `vendor_hisilicon` + `hispark_taurus`。
5. **Gitee 网页树被 WAF 拦截**：`curl https://gitee.com/openharmony/<repo>` 一律返回 **HTTP 405 / JS 挑战页（nox_*.js）**，无 User-Agent 也无法绕过。因此“浏览 gitee web tree/README/tags 页”的计划**不可行**，全部改用 `git ls-remote`（分支/标签）+ `git clone --filter=tree:0|blob:none`（树结构）+ `git show <ref>:<path>`（单文件）完成，证据强度等价或更高。
