## 1. 发展历程

### 1.1. 核心问题
**——机器如何获得智能，如何理解世界，并给出有用的答案**

围绕该问题，AI的发展大致有三条重要路线
- 符号主义：智能来自规则和推理
- 统计学习：智能来自数据中的规律
- 神经网络：智能来自可学习的表示

LLM的出现，正是这些路线长期积累后的结果，既继承了AI对智能的追问，吸收了统计学习从数据中建模的方法，也依赖神经网络强大的表示学习能力。

### 1.2. LLM简史

![[Pasted image 20261104105033.png]]

（1）从词向量到Transformer（2003-2017）
	早期关键问题：机器如何理解一个词的含义？

- 把词变成向量，让语义相近的词再空间中也更接近（Word2Vec）
- 模型学会在生成时关注输出里最相关的部分（Attention）
- 模型可以同时看整段文本里词与词的关系（Transformer）

（2）Transformer革命与早期探索（2017-2019）
	2017年，Google发表《Attention Is All You Need》

- Transformer架构通过自注意力机制（Self-Attention）显著缓解RNN/LSTM在长距离依赖和并行训练上的瓶颈，也让大规模语言模型训练变得更加可行
- Self-Attention让模型在处理一句话时，可以同时观察所有词之间的关系，判断哪些词更重要、哪些词应该彼此关联

（2）从相似度到Attention

- 相似度计算方式：

| **方法** | **基本原理**                                            | **常见位置**           | **适合场景**                        |
| ------ | --------------------------------------------------- | ------------------ | ------------------------------- |
| 点积     | 将两个向量对应维度相乘后求和。  <br>两个向量方向越一致、数值越大，分数越高            | Attention score    | 适合在模型内部快速计算相关性，尤其是 Q 和 K 的匹配    |
| 余弦相似度  | 计算两个向量夹角的余弦值，重点看方向是否接近。  <br>不太关心向量长度，更关心“语义方向”是否一致 | 向量检索、RAG、语义搜索      | 适合比较文本、问题、文档之间的语义相似度            |
| 欧氏距离   | 计算两个点在空间中的直线距离。  <br>两个点离得越近，表示越相似                  | 聚类、传统机器学习、部分向量检索场景 | 适合空间距离有明确意义的场景，但在高维语义向量中不一定总是最优 |

- 对于复杂矩阵，往往不是每个方向都同等重要，有些方向承载主要信息，有些方向只是细节或噪声。（SVD奇异值分解&低秩近似）

| **概念** | **基本原理**                                          | **和 LLM 的关系**                 | **常见应用**                   |
| ------ | ------------------------------------------------- | ----------------------------- | -------------------------- |
| SVD    | 将一个矩阵分解成几个更简单的矩阵，拆出其中最重要的方向和强度（把复杂矩阵拆成几个主要方向）     | 帮助理解降维、压缩、低秩近似                | 模型压缩、降维、矩阵分析、理解 LoRA 的数学基础 |
| 低秩     | 如果一个矩阵的大部分信息可以由少数几个方向表达，就可以用更小的矩阵近似它（用更少参数表达主要变化） | LoRA 利用低秩矩阵近似参数更新，不必完整微调整个大矩阵 | LoRA、参数高效微调、模型压缩           |

### 2.2. 预测与评估
**——在当前上下文后面，下一个token最可能是什么**

![[Pasted image 20261104151006.png]]

- 语言模型真正学习的是：P（下一个token | 前面的上下文）
- prompt本质上是在改变上下文，上下文会改变后续token的概率分布

如何衡量模型预测得好不好：
- 语言模型常用的loss是交叉熵（对单个token来说，正确token概率越高，loss越小；反之亦然）
- 从另一个角度看，训练语言模型就是最大似然：让训练语料里的句子，在模型看来越来越“可能出现”

### 2.3. 学习与优化
**——模型如何从错误中变好**

训练目标：
- 最小化Loss函数，即min L(θ)
- 最大化训练文本出现的概率

找到参数应该怎么改：
- LLM有大量参数，如果某个参数稍微变大，loss会变大还是变小？
- 基于以下概念，有梯度方向（loss上升最快方向）&负梯度方向（loss下降最快方向）

|**概念**|**数学原理**|**在 LLM 中的作用**|
|---|---|---|
|导数|衡量一个变量变化时，函数如何变化|看参数变化会不会影响 loss|
|偏导数|多个变量中，只看其中一个变量的影响。|看某个参数对 loss 的影响|
|梯度|所有偏导数组成的向量|给出整体参数更新方向|

如果预测错了，如何判断前面每一层、每一个参数应该承担多少责任？
- 反向传播（链式法则）
~~~
如果 L 依赖 y，y 又依赖 x，  
那么 L 对 x 的影响可以拆成：  
  
dL/dx = dL/dy × dy/dx （dy/dx 表示 y 对 x 求导数）
~~~

![[Pasted image 20261104152722.png]]

梯度下降与优化器
- 基础更新参数公式：θ_new = θ_old - η × ∇L(θ)
- 真实LLM训练里，通常不会只用最朴素的梯度下降，而会用更复杂的优化器，例如Adam

|**优化方法**|**数学思想**|**直觉理解**|
|---|---|---|
|SGD|按当前梯度更新参数|每次看当前坡度走一步|
|Momentum|累积历史梯度方向|不只看当前一步，也看惯性|
|Adam|同时估计梯度均值和梯度波动|给不同参数自适应调整步长|

如何保证训练稳定性？正则化、凸优化与约束思想

|**问题**|**表现**|**数学原因**|
|---|---|---|
|学习率太大|loss 震荡或爆炸|每一步跨得太远|
|学习率太小|训练很慢|每一步变化太小|
|梯度爆炸|参数更新失控|梯度数值过大|
|梯度消失|前面层学不动|梯度经过多层后变得很小|
|过拟合|训练集好，测试集差|模型记住噪声而不是规律|

- 正则化（解决过拟合一类方法）：在原loss后加入惩罚项，即 L_total = L_train + λR(θ) （惩罚强度 * 对参数复杂度的惩罚）
