# 智能体 AI、AI Infra 与具身智能：三个方向怎么分、怎么比、往哪走

> 调研时间：2026 年 11 月。数字均标注来源，行业报告类数据（出货量、融资额）口径不一，当作量级参考而非精确值。
> 本文想回答三件事：这三个词各自指什么、它们是什么关系、未来两三年各自的胜负手在哪。

---

## 1. 先摆正：三者不在同一层

很多讨论把这三个词并列，仿佛是三家公司、三条赛道。其实它们分处产业链的不同位置：

| | 位置 | 卖的是什么 | 一句话 |
|---|---|---|---|
| **AI Infra** | 供给端 | 产能（token/算力） | 把电和芯片变成可计价的 token |
| **智能体 AI** | 组织端 | 劳动（任务完成） | 把 token 组织成能交付的结果 |
| **具身智能** | 落点 | 劳动 + 身体 | 把结果落到物理世界的动作上 |

一个比喻：**AI Infra 是电厂和电网，智能体是跑在电上的软件与操作系统，具身智能是需要用电驱动的新一代终端。**

这个分层很重要，因为三者的**周期、资本结构、护城河完全不同**——用同一套估值逻辑去看它们，几乎必然看错。

---

## 2. 智能体 AI（Agentic AI）

### 2.1 它到底新在哪

LLM 的默认形态是"输入→输出"：给问题，给答案。智能体把这个过程拉长成"目标→计划→动作→观察→修正→交付"。

用 matt33 那篇 Agent 文章的对比最准确：

> "普通 LLM 应用的失败，通常只是'回答错了'；Agent 的失败可能会变成'执行错了'。"

所以它不是"更强的聊天机器人"，而是**把模型放进一个带工具、带状态、带校验的执行系统里**。技术栈大致五层：

1. **规划**：任务分解、阶段性计划、何时停下来问人；
2. **工具**：Function Calling 负责"表达调用"，MCP 负责"统一接口"；
3. **状态与记忆**：任务状态机、工作记忆、跨会话记忆；
4. **验证**：测试、引用、规则校验、Verifier——这一层最容易被低估；
5. **安全边界**：权限隔离、沙箱、高风险操作人工确认、审计日志。

### 2.2 现状：说得多，真跑起来的少

Menlo Ventures 2025 年的企业调研给了个冷水数据：

> 只有 **16%** 的企业部署、**27%** 的创业公司部署，算得上"真正的 agent"（模型自己规划、执行、观察反馈、调整行为）；其余多数仍是"模型调用外面套一层 if-then"。

与此同时，横向 AI 应用里 **86%** 的钱花在 copilot 上（$7.2B），agent 平台还是小头。也就是说：**2025-2026 年的主流仍是"人机协作"，不是"自主代理"。**

### 2.3 三个真瓶颈

- **可靠性**：多步链路的误差是指数累积的，10 步每步 95% 正确，整体就只剩 60%；
- **责任**：agent 删了数据、发了邮件、下了单，谁负责？这条不解决，企业不敢放开；
- **评测**：从"答案对不对"变成"任务完成没有"，评测集得自己造，公开榜单基本无效。

### 2.4 商业形态正在变

从"按席位卖"转向"按结果卖"（outcome-based pricing）——不按人头收费，按解决的工单、达成的转化、节省的工时收费。这个转变如果成立，agent 公司的收入曲线会跟 SaaS 完全不同（更接近外包/BPO），毛利结构也会变。

## 3. AI Infra

### 3.1 它包含什么

国内讲 AI Infra，常被窄化成"GPU 集群"。实际至少三层：

| 层 | 内容 | 代表 |
|---|---|---|
| **硬件** | GPU/ASIC、HBM、互联（NVLink/IB）、网络交换、液冷、电力 | NVIDIA、AMD、博通、TPU/Trainium |
| **系统软件** | 训练框架、并行策略、推理引擎、调度、存储 | CUDA、Megatron、vLLM、SGLang、Ray、K8s |
| **工程管线** | 数据流水线、评测、可观测、故障恢复、多租户 | 各家自建 + 商业化平台 |

再往外是**服务形态**：公有云、neocloud（CoreWeave、Nebius 这类）、以及企业私有集群。

### 3.2 这一层的经济性，才是重点

Infra 的本质是**重资产生意**，所以要看四个数，而不是看参数量：

- **capex 强度**：2026 年四大云厂商合计资本开支指引已到 **7200–7450 亿美元**（Alphabet 1950–2050 亿、Amazon 约 2200 亿、Microsoft 约 1750 亿、Meta 1300–1450 亿）；
- **折旧周期**：GPU 按几年折？这直接决定账面利润；
- **利用率**：集群空转是这行最大的隐性亏损；
- **单位 token 成本**：推理占比上升后，这个数就是竞争力本身。

### 3.3 需求侧有多猛

NVIDIA 2026 年 8 月发的财报（FY2027 Q2）：单季营收 **962 亿美元**，同比 **+106%**，环比 +18%；下季度指引 **1080 亿美元**。黄仁勋在财报里那句总结很直白：

> "AI has reached its inflection point. It's doing useful work. Its tokens are productive and profitable. Now, compute is revenue."

这句话信息量在于：**算力从成本项变成了收入项**——只要 token 能卖钱，capex 就不是费用而是产能投资。这也是为什么 2027 年"超大规模 capex 破万亿"的预期能被市场接受（NVIDIA CFO 引用的第三方预测）。

### 3.4 竞争格局的三个变化

1. **自研 ASIC 上量**：TPU、Trainium、MTIA 从"备胎"变成主力之一，理由是推理成本；
2. **瓶颈从芯片转向电力与并网**：机柜功率密度上去之后，拿地、拿电、拿冷却水比拿卡更难；
3. **融资结构复杂化**：Alphabet 的债务从一年前约 160 亿涨到约 1000 亿，还发了 800 亿股权；Meta 靠合资（BlackRock 的 1GW 项目）摊薄。**这行的风险已经从技术风险变成资产负债表风险。**

## 4. 具身智能

### 4.1 定义与闭环

具身智能 = 有身体的智能。核心不是"机器人"，而是**闭环**：

- **执行闭环**：观察 → 状态估计 → 决策 → 动作 → 物理反馈 → 纠错；
- **学习闭环**：把交互经验变成新能力（数据采集 → 训练 → 部署 → 再采集）。

matt33 的五篇系列把这条链拆得很干净，值得按顺序看：空间表示（自由度、坐标系、SE(3)）→ 运动学/动力学/控制（FK、IK、Jacobian、PID、阻抗、MPC）→ 感知与状态估计（标定、RGB-D、位姿估计、滤波、SLAM）→ 任务与运动规划（抓取、碰撞、轨迹优化、重规划）。

一个容易被忽略的点，那篇讲感知的文章说得很到位：

> "VLA 可以将部分感知与状态估计能力吸收到模型内部，但无法绕过空间几何、时间同步和物理约束。"

### 4.2 技术范式：VLA 是当前主线

VLA（Vision-Language-Action）把"看图 + 听懂话 + 出动作"放进一个模型，端到端替代传统的"感知-规划-控制"模块化管线。2025-2026 的主要玩家：

- 海外：Figure Helix、Physical Intelligence π 系列、NVIDIA GR00T；
- 国内：智元 GO-1、星动纪元 ERA-42、银河通用 GraspVLA、千寻 Spirit。

两条架构路线并行：**双系统**（慢思考的大模型 + 快执行的策略）与**单一大模型**。此外世界模型（Cosmos、Genie、V-JEPA）负责"预测动作后果"，扩散策略负责动作生成，神经符号负责可验证的约束。

### 4.3 2026 年的产业现实

- **出货**：中国厂商包揽前六（宇树约 5500 台、智元 4000+ 台、乐聚/加速进化/松延各约 1000 台、优必选约 600 台），合计占全球约 **74%**；同期 Optimus 试产不足千台，Figure 全年约 150 台。
- **资本**：2025Q1–2026Q1 国内融资 324 起、超 390 亿元；全球人形融资约 578 亿元，中国占七成以上。
- **成本**：单台（20–40 自由度）成本里，**执行器 + 传感器占 60% 以上**——这就是为什么"一体化关节、六维力传感器、灵巧手、电子皮肤"是国产替代的主战场。
- **数据**：四条路线并存——遥操作示教（质量锚点）、仿真合成（规模）、人类视频（规模化潜力最大）、UMI 手持采集（把成本打到消费级）。

### 4.4 瓶颈排序（我的判断）

1. **数据**：不是"缺数据"，是缺"带动作标签、跨本体、可复用"的数据；
2. **可靠性**：工业场景要的是 MTBF 几千小时，不是 demo 成功一次；
3. **成本**：整机降到 10 万元级，才谈得上规模铺开；
4. **模型**：VLA 的 scaling 才刚开始（有报告称参数激活效应阈值约 7B，而主流商用模型还在 4B 附近），这条曲线还没走完。

## 5. 三者对比

| 维度 | 智能体 AI | AI Infra | 具身智能 |
|---|---|---|---|
| **核心问题** | 怎么把任务可靠地做完 | 怎么把算力便宜地变成 token | 怎么把决策变成物理动作 |
| **技术瓶颈** | 长链路可靠性、验证、责任 | 电力、互联、利用率、折旧 | 数据、硬件成本、MTBF |
| **资本属性** | 轻资产、拼工程与场景 | 极重资产、拼资本与供应链 | 中重资产、拼制造与迭代 |
| **护城河** | 工作流嵌入 + 审计信任 | 生态（CUDA）+ 产能 + 电力 | 本体成本曲线 + 数据飞轮 + 场景准入 |
| **成熟度** | 早期（16% 真 agent） | 高速扩张期 | 量产爬坡期 |
| **收入模式** | 订阅 → 按结果 | 卖卡/卖云/卖 token | 卖整机 + 服务 + 租赁 |
| **周期** | 3–5 年见分晓 | 2–3 年一轮产能周期 | 5–8 年 |
| **最大风险** | ROI 证伪、安全事故 | 过度投资、回报错配 | 场景碎片化、硬件毛利 |
| **关键指标** | 任务完成率、单任务成本 | capex/收入比、利用率、token 成本 | 出货量、单台成本、MTBF |
| **人才画像** | 后端 + 评测 + 安全 | 系统/编译/网络/运维 | 控制 + 机器人学 + 具身模型 |

一句话版本：**Infra 赌的是产能，Agent 赌的是信任，具身赌的是成本曲线。**

## 6. 三者怎么咬合

不是三条平行线，是一个正反馈环：

```
算力成本下降 ──→ Agent 能跑更长的任务 ──→ token 需求上升 ──→ Infra 扩产
      ↑                                                      │
      └──────── 具身产生新的数据与负载 ←── 世界模型/仿真 ←─────┘
```

具体咬合点有三个：

1. **Agent 是 Infra 最大的增量需求**。聊天是短请求，agent 是长任务：一次任务几十轮工具调用，token 消耗高一个数量级。NVIDIA 把"agentic AI factory"直接写进产品叙事，就是这个逻辑。
2. **具身是 Agent 的物理形态**。同一个"规划-执行-验证"循环，只是动作从 API 调用变成关节力矩。所以做 agent 的工程经验（状态机、验证、沙箱）可以直接迁移。
3. **Infra 决定另外两个的可行性**。token 价格降一个数量级，agent 的经济账才成立；仿真与合成数据的成本降下来，具身的 data flywheel 才转得动。

反过来的约束也存在：**如果 agent 的商业化证伪，Infra 的 capex 就失去需求支撑**——这是 2027 年最值得盯的尾部风险。

## 7. 前景：三张时间表

### AI Infra：2026–2028，从"缺卡"到"缺电"

- 短期（2026–2027）：产能仍是瓶颈，capex 继续超预期，自研 ASIC 份额上升；
- 中期（2027–2028）：**电力与并网**成为硬约束，集群选址向有电的地方迁移；
- 风险点：如果推理收入增速跟不上折旧，2027 下半年可能出现第一轮"产能过剩"叙事。

盯这三个数：**推理占数据中心收入的比例、单位 token 价格、集群平均利用率**。

### 智能体：2026–2028，从 copilot 到"可交付"

- 迁移路径：辅助（人做主）→ 半自动（人审批）→ 自动（人抽检）→ 自主（人定目标）；
- 关键不是模型变强，而是**验证与责任机制**变清晰（审计日志、可回滚、权限最小化）；
- 里程碑：出现第一个"按结果收费"且规模化盈利的 agent 产品。

盯这三个数：**真 agent 占比（16% 会走到多少）、单任务成本、人工介入率**。

### 具身智能：2026–2030，先 ToB，后 ToC

- 2026–2028：结构化场景放量（汽车/3C 产线、仓储、危险作业），拼交付与可靠性；
- 2028–2030：跨体态迁移与持续学习突破，才谈得上"具身通才"；
- 家庭场景是最后一个，也是最难的一个（非结构化 + 安全 + 成本三重约束）。

盯这三个数：**年出货量、单台成本、无人工干预连续运行时长**。

## 8. 三条可能反共识的判断

1. **Agent 的胜负手不在模型，在"验证"**。谁的验证体系能把人工介入率压下来，谁就能按结果收费。模型能力会商品化，验证体系不会。
2. **Infra 的稀缺性正在从芯片转向电力**。当单机柜功率往 200kW 走，拿电、拿水、拿并网许可的难度超过拿卡。这会让"有电的地方"重新获得产业话语权。
3. **具身智能的中国优势在制造与数据，不在模型**。74% 的出货份额来自供应链与工程迭代速度；但 VLA 的模型创新仍以海外为主。这个错位既是优势也是风险——如果模型收敛到少数几家，本体厂会退回代工位置。

## 9. 如果要做选择

- **工程师**：想做深技术选 Infra（系统、编译、网络、推理引擎，技能半衰期最长）；想做产品选 Agent（离业务近，反馈快）；有机器人/控制背景选具身（门槛最高，供给最少）。
- **创业者**：Agent 的窗口在"垂直工作流 + 责任承担"，不要做通用 agent；具身的窗口在"核心零部件 + 场景集成"，不要做通用本体；Infra 的窗口基本关闭（除非有电力或供应链资源）。
- **投资人**：Infra 看订单与折旧政策，Agent 看留存与人工介入率，具身看出货与 MTBF。三个方向都别用 SaaS 的倍数去套。
