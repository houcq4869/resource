# 三大方向详细调研：智能体 AI、AI Infra、具身智能（2026.11）

> 调研时间：2026 年 11 月。方法：一手来源优先（公司财报与官方博客、论文、Stanford AI Index），行业报告与媒体报道标注为二手；数字尽量给日期与口径，无法核实的明确标注。
> 结构：先给全景，再逐方向拆「技术架构 → 能力现状 → 技术瓶颈 → 产业数据 → 竞争格局 → 趋势与分歧」，最后横向对比与观察指标。

---

## 0. 三条曲线的位置

用 Stanford HAI《2026 AI Index》（覆盖 2025 年）的几组数字做锚点：

| 指标 | 数值 | 含义 |
|---|---|---|
| 组织 AI 采用率 | **88%**（至少一个职能用 GenAI 的组织 70%） | 普及已完成，进入深水区 |
| **agent 部署率** | **各业务职能均为个位数** | 智能体仍在早期 |
| OSWorld 任务成功率 | 12% → **66.3%**（人类 72.35%） | 一年涨 5 倍，仍约 1/3 失败 |
| 真实家庭任务机器人成功率 | **12%**（仿真 RLBench 89.4%） | sim2real 鸿沟被量化 |
| 美国 AI 私人投资（2025） | 2859 亿美元 | 资本仍在上行 |
| 美国数据中心数量 | 5427 个（第二名的 10 倍以上） | 基础设施高度集中 |
| 前沿模型能力 | HLE 一年 +30 个百分点；Arena 前四名挤在 25 Elo 内 | 能力在涨，差距在缩 |

三条曲线可以这样概括：**能力陡升、采用普及、但"真正自主"极少**。这个落差是三个方向所有叙事的来源，也是判断它们各自走到哪一步的基准线。

## 1. 智能体 AI

### 1.1 技术架构：2026 年已经收敛为「Harness」

业界现在把一整套东西叫 **harness**：模型 + 上下文引擎 + 工具系统 + 运行时 + 验证器。模型只是其中一个零件。

```
目标 → 规划(plan) → 工具调用(act) → 观察(observe) → 校验(verify)
         ↑                                            │
         └──────── 状态与记忆(state / memory) ←────────┘
```

| 层 | 解决什么 | 2026 年的状态 |
|---|---|---|
| 控制流 | 谁决定下一步 | 从"模型自由发挥"退回到 **workflow 兜底 + agent 局部决策** 的混合模式 |
| 上下文 | 每轮给模型看什么 | prompt engineering → **context engineering**：检索、压缩、摘要、结构化状态 |
| 工具 | 怎么作用于外部世界 | Function Calling 做表达，MCP 做协议，沙箱做隔离 |
| 验证 | 怎么确认做对了 | 编译器 / 测试 / 规则 / 引用 / 人工抽检——**当前最大的工程差异点** |

**训练侧**的最大变化：能力不再只靠 prompt 堆，而靠**轨迹数据 + 可验证奖励（RLVR）**。可验证环境（代码执行、单元测试、浏览器状态机）成了新的数据资产——谁能造出又多又稳的 env，谁就能训出更强的策略。

### 1.2 能力现状：一年 5 倍，但仍有三成静默失败

- **OSWorld**：12% → 66.3%，距人类基线 72.35% 只差 6 个点；
- **失败形态变了**：从"答错"变成"看起来做完了，其实没做对"——静默失败比报错更危险；
- **长任务时域**：前沿模型的稳定任务时长持续翻倍，但距"连续工作一整天"仍有距离；
- **锯齿依旧**：IMO 金牌级推理 + 读模拟时钟 50.6%（人类 90.7%）。

工程经验值（非精确统计）：任务步数越多，端到端成功率下降越快，因此生产系统普遍用"分阶段 + checkpoint + 人工确认"把长任务切成短任务。

### 1.3 技术瓶颈：五个，其中两个工程解决不了

| 瓶颈 | 能否靠工程缓解 | 现状 |
|---|---|---|
| 误差累积 | 能（验证器、回滚、分阶段） | 有效但成本高 |
| **持续学习** | **不能**（在模型侧） | agent 跨任务不积累，每次从零开始 |
| 评测 | 能但很贵 | 公开基准饱和 + 分布外失效，必须自建任务集 |
| 上下文 | 部分 | 长上下文有"中间遗忘"，压缩会丢约束 |
| 安全权限 | 必须 | 注入、越权、副作用不可逆 |

最关键的是**持续学习**：如果模型不能在线学习，"越用越懂你"就只能靠外挂记忆模拟，天花板很低。这也是 agent 目前"演示惊艳、复购一般"的技术根因之一。

### 1.4 产业数据

- **企业支出**：2025 年企业生成式 AI 支出 **370 亿美元**，同比 3.2 倍；其中应用层 190 亿（超一半），编码单项 40 亿（占部门级 AI 的 55%）；
- **采购结构**：76% 的企业选择买而不是自建（2024 年是 53% 买）；
- **模型份额**：企业 LLM API 市场 Anthropic 约 40%，OpenAI 约 27%；
- **真 agent 占比**：仅 **16%** 的企业部署、27% 的创业公司部署算得上"真 agent"；横向 AI 里 86% 的钱仍花在 copilot 上；
- **采用率**：88% 的组织在用 AI，但 agent 在各业务职能的部署率都是个位数。

这两组数字要一起读：**AI 的采用率已经很高，但 agent 的渗透率极低**。说明瓶颈不在"要不要用"，而在"敢不敢让它自己干"。

### 1.5 竞争格局：四层，价值在往两头走

| 层 | 代表 | 护城河 |
|---|---|---|
| 模型层 | Anthropic、OpenAI、Google | 能力 + 成本 |
| Harness / 产品层 | Claude Code、Codex、Cursor | 上下文引擎 + 工具 + 验证闭环 |
| 垂直应用层 | Sierra（客服）、Harvey（法律）、Decagon | 场景数据 + 责任承担 |
| 协议层 | MCP、A2A | 生态位（难变现，但卡位关键） |

一个判断：**中间层（通用 agent 平台）最危险**——上被模型厂吞，下被垂直应用绕。活下来的要么有独有环境（代码仓库、浏览器、企业系统），要么有责任能力（敢签字）。

### 1.6 趋势与分歧

- 12 个月内最确定：**从 copilot 迁移到"人在环上的 agent"**，按结果收费的试点增多；
- 最不确定：模型侧如果出现真正的持续学习，现有记忆/编排工程会被大幅重写；
- 分歧点：多智能体是不是有效范式。目前证据偏负面——多数"多 agent"是把串行流程拆成并行的表演。

## 2. AI Infra

### 2.1 技术栈：四层，越往下越像传统产业

| 层 | 内容 | 关键词 |
|---|---|---|
| 芯片与封装 | GPU/ASIC、HBM、CoWoS | 算力密度、HBM 带宽、良率 |
| 系统与互联 | 机柜、NVLink/UALink、InfiniBand、光模块 | scale-up vs scale-out |
| 集群与调度 | 万卡训练、容错、存储 | 并行策略、checkpoint、故障恢复 |
| 推理服务 | 引擎、批处理、缓存 | prefill/decode 分离、PagedAttention、投机解码、量化 |

2026 年最明显的重心转移：**优化从训练转向推理**。原因是负载结构变了——agent 的长任务让 token 消耗涨一个数量级，推理成本直接决定业务能否算过账。

### 2.2 技术瓶颈：三道墙

- **内存墙**：算力增速 > HBM 带宽增速 > 电力增速。Decode 阶段是 memory-bound，"算力翻倍"未必带来"吞吐翻倍"；
- **互联墙**：万卡以上通信吃掉线性加速，NVLink 域 + IB/以太网分层是标配，CPO 光互联 2026 年开始规模部署；
- **电力墙**：单机柜向 200kW 走，液冷从可选变必须，800V 直流开始落地。

还有一道隐形的：**可靠性**。万卡集群日均故障是常态，弹性训练与快速 checkpoint 是核心技术，但很少被拿出来讲。

### 2.3 推理经济学：三个可优化项

1. **算力利用率**：continuous batching 把 GPU 填满；
2. **显存效率**：KV Cache 分页、量化、分层卸载（HBM→DRAM→SSD）；
3. **计算量**：投机解码（小模型起草 + 大模型验证）、MoE 稀疏激活。

三项叠加，构成"单位 token 成本逐年下降"的工程基础——也是 agent 与具身能算得过账的前提。

### 2.4 产业数据

- **NVIDIA**（FY2027 Q2，截至 2026-07-26）：单季营收 **962 亿美元**，同比 **+106%**，环比 +18%；Q3 指引 **1080 亿**；Vera Rubin 平台进入满产；
- **云厂商 capex**（2026 指引，四大合计）：**7200–7450 亿美元**；Alphabet 1950–2050 亿、Amazon 约 2200 亿、Microsoft 约 1750 亿、Meta 1300–1450 亿；
- **2027 预期**：NVIDIA CFO 引用第三方预测，超大规模 capex 有望破 1 万亿美元（预测，非事实）；
- **融资结构在变**：Alphabet 债务从约 160 亿涨到约 1000 亿，另发 800 亿股权；Meta 靠合资（BlackRock 的 1GW 项目）分摊——**风险从技术转向资产负债表**；
- **负载结构**：agent 与物理 AI 成为新增负载来源，NVIDIA 直接把产品叙事写成"agentic AI factory"。

### 2.5 竞争格局

| 阵营 | 打法 | 优势 | 风险 |
|---|---|---|---|
| NVIDIA | 整机柜 + 互联 + 软件生态 | CUDA 锁定、迭代节奏 | 客户自研替代 |
| AMD | 开放生态 + 大客户定制 | 性价比、供给多元 | 软件栈 |
| 云厂商 ASIC | TPU / Trainium / MTIA | 推理成本、垂直整合 | 只服务自家 |
| Neocloud | CoreWeave、Nebius | 弹性、专注 | 融资成本、客户集中 |

一个结构性变化：**自研 ASIC 从"备胎"变成主力之一**，理由是推理经济性，而不是训练性能。

### 2.6 趋势与分歧

- 最确定：**电力成为第一约束**，选址、并网、冷却的权重上升；
- 最不确定：2027 年是否出现"产能过剩"叙事——取决于推理收入能否跟上折旧；
- 分歧点：万亿 capex 是"投资"还是"军备竞赛"。支持方看 token 收入增速，反对方看自由现金流与折旧年限。

## 3. 具身智能

### 3.1 技术栈：五层，每层都有物理约束

| 层 | 解决什么 | 关键技术 |
|---|---|---|
| 本体与硬件 | 身体能不能动 | 关节模组、灵巧手、力/触觉传感器、电池散热 |
| 控制 | 怎么动得稳 | FK/IK、Jacobian、动力学、PID、阻抗、MPC、MPC+RL |
| 感知与状态 | 我在哪、东西在哪 | 标定、RGB-D/点云、位姿估计、滤波、SLAM |
| 规划 | 先做什么、怎么到 | 任务规划、抓取规划、运动规划、碰撞检测、重规划 |
| 策略/模型 | 怎么学会做 | VLA、扩散策略、flow matching、世界模型 |

和纯软件最大的区别：**下层错了，上层再聪明也没用**。标定偏 1 度、时间戳差 10ms，都会让"语义正确"变成"物理失败"。

### 3.2 VLA：主线明确，路线未收敛

| 路线 | 结构 | 优点 | 缺点 |
|---|---|---|---|
| 双系统 | 慢思考大模型 + 快执行小模型 | 兼顾推理与实时 | 系统复杂、接口损耗 |
| 单一大模型 | 端到端出动作 | 简洁、可 scaling | 实时性差、训练难 |

动作生成也在分化：**离散 token 化**（把动作当词，易与 LLM 统一）vs **连续生成**（扩散 / flow matching，更平滑但更慢）。

工程实现上，Figure 的 Helix 是最透明的一手样本：**System 2 是 7B 的 VLM，7–9 Hz 做语义理解；System 1 是 80M 的 visuomotor transformer，200 Hz 直接输出 35 个自由度的上半身连续动作**，跑在机器人双低功耗 GPU 上，单一权重、无任务微调，训练数据约 500 小时遥操作。它没有用 diffusion——为了 200Hz 的实时性，宁可放弃迭代采样的生成质量。这是一个很有代表性的取舍：**在人形上半身，"实时"比"好看"更重要**。

其他路线的 2026 年状态（含明确的时间差，引用时注意）：

| 团队 | 路线 | 状态 |
|---|---|---|
| Physical Intelligence | π0.5 分层 + π\*0.6 用 RECAP 做"专家纠错 + 自主经验"的 RL | espresso 等任务成功率 >90%；π\*0.6 权重**未开源** |
| NVIDIA | GR00T N1.7 商用；**GR00T N2**（world-action model，官方称新环境新任务成功率是领先 VLA 的 2 倍以上） | N2 为**预览**，年底才可用 |
| 智元 | GO-3 Preview（WRAM 架构，预训练—后训练—部署后持续学习） | 2026-10-29 发布，称三榜第一（成绩未核实），年底开源 |
| 1X | NEO 家用，$20,000 或 $499/月 | 2026 年晚些时候交付，**任务仍由远程操作员驱动** |

2026 年一个值得记的转折：Figure 在 9 月的 Helix 2.5 上验证了**"人类数据 → 人形机器人"的迁移 scaling law**——反复翻倍预训练数据（其 Index 数据集，来自人类行为），下游动作预测的 loss 平滑下降，甚至能在训练前预测最大规模实验的 loss。他们给出的一个关键数字：**仅靠预训练，零样本成功率从 9% 提升到 56%**。

这是"具身也能 scaling"的第一个硬证据，但它同时说明：**瓶颈是数据，且是人类行为数据，不是机器人遥操作数据**。

### 3.3 数据：核心矛盾，且答案在变

| 路径 | 成本 | 质量 | 规模潜力 |
|---|---|---|---|
| 遥操作示教 | 最高 | 最高（真值） | 低 |
| 仿真合成 | 低 | 中（有 gap） | 高 |
| 人类视频 | 低 | 低（无动作标签） | 最高 |
| UMI 手持采集 | 中低 | 中高 | 中高 |

AI Index 2026 的量化很刺眼：**仿真 RLBench 操作成功率 89.4%，真实家庭任务只有 12%**。但 Figure 的 Helix 2.5 又展示了另一面——在 30 个未见过的真实家庭里零样本完成整理客厅、叠毛巾、铺床。两个数字并不矛盾：**基准测的是"通用平均"，demo 测的是"选定任务"**。看具身进展，必须同时看这两栏，只信一边都会误判。

### 3.4 硬件：成本结构决定商业化节奏

单台人形（20–40 自由度）成本中，**执行器 + 传感器占 60% 以上**。降本路径清晰：一体化关节、准直驱方案、六维力传感器国产化、灵巧手规模化（2025 年已有厂商灵巧手出货超万台）。

成本曲线决定渗透顺序：**工业（ROI 可算）→ 商用服务（半结构化）→ 家庭（非结构化，最后）**。

### 3.5 产业数据

**出货（Counterpoint，2026 H1，一手）**：全球 **22000+ 台，同比近 +300%**；Top5 占 86%——智元约 9700 台（>43%）、宇树 >7000 台（31%）、银河通用 >1100 台（约 5%）、优必选千台级（4.4%）、乐聚 650 台（2.9%）。Counterpoint 预测 2026 全年 >5 万台（+210%）。

**应用结构（同一来源）**：文娱表演 + 数据生产/科研合计 **>60%**，服务引导约 19%，智能制造 13%，仓储物流 5%。这组数字比出货量更重要——**目前大多数人形机器人不从事生产性劳动**。

**预测分歧（必须并列看）**：Goldman Sachs 2026-09 把 2026 年预测从 5.1 万台上调到 **7.5 万台**；Berg Insight 只给 **1.6 万台**；Counterpoint 给 >5 万台。**1.6 万 vs 7.5 万差 4.7 倍**，说明"出货"的口径（含科研样机、租赁、出口）尚未统一。

**对比海外**：Optimus 2025Q3 试产不足千台，Figure 2025 全年约 150 台；但 Figure 2026 已把 F.03 送进 BMW 产线，并签下最多 10 万张 Vera Rubin GPU 的算力协议——**机器人公司开始自建算力**。

**资本与 IPO（一手）**：宇树科技 2026-03-20 科创板受理 → 06-01 过会 → 07-02 注册 → **08-19 上市**（688836），发行价 ¥150.80，募资 **42.02 亿元**，对应估值约 **610 亿元**。招股书口径：2025 年营收 17.08 亿元（+335%），扣非净利 6.00 亿元（+674%），毛利率 **60.27%**，人形出货 >5500 台。融资侧，2025Q1–2026Q1 国内融资 324 起、超 390 亿元，中国占全球人形融资七成以上（二手）。

**政策（一手）**：2025 年"具身智能"首次写入《政府工作报告》；2026 年"十五五"规划纲要列为未来产业方向（券商解读，原文未逐字核对）。发改委 2025-11 发布会口径：国内人形机器人企业 **>150 家**，产业"以超 50% 增速跨越式发展"，2030 年目标千亿元规模；下一步三条——建标准与准入退出机制、攻关"大小脑协同 + 云边算力适配 + 仿真真机数据融合"、建训练与中试平台。

### 3.6 趋势与分歧

- 最确定：**2026–2028 是结构化场景的量产爬坡**（汽车、3C、仓储、危险作业），拼交付与可靠性；
- 一个可验证的窗口：**2026 年底**，NVIDIA GR00T N2（宣称新任务成功率是 VLA 的 2 倍）正式可用、智元 GO-3 开源——这是检验"世界-动作模型"是否真优于 VLA 的第一个公开机会；
- 最不确定：家庭场景的时间表。Helix 2.5 证明了"能进陌生家庭做三件事"，但离"可靠地做一百件事"还很远；
- 分歧点一：**人形 vs 专用形态**。轮式/专用在多数场景更经济，人形的价值在于"通用性溢价"，这个溢价目前还没被验证；
- 分歧点二：**通用模型 vs 场景专用**。若 VLA 收敛到少数基础模型，本体厂会退回代工位；若不收敛，场景数据就是壁垒。

## 4. 横向对比

| 维度 | 智能体 AI | AI Infra | 具身智能 |
|---|---|---|---|
| **2026 技术成熟度** | 单任务可用，长任务不可靠 | 工程成熟，受物理约束 | 受控场景可用，开放场景早期 |
| **进步斜率** | 快（benchmark 一年 5 倍） | 中（按代际迭代） | 快（数据 scaling 刚验证） |
| **技术瓶颈** | 持续学习、验证、安全 | 内存墙、互联、电力 | 数据、可靠性、成本 |
| **瓶颈性质** | 软件/模型 | 物理 + 资本 | 物理 + 数据 |
| **产业阶段** | 早期渗透（个位数） | 高速扩张 | 量产爬坡 |
| **单位经济学** | 按任务计费，毛利待验证 | 重资产，折旧决定利润 | 硬件毛利 + 服务 |
| **护城河** | 场景数据 + 验证体系 | 生态 + 产能 + 电力 | 本体成本 + 数据飞轮 |
| **12 个月看点** | 真 agent 占比能否破 30% | 2027 capex 与电力约束 | 出货翻倍与单台降本 |
| **最大风险** | ROI 证伪、安全事故 | 产能过剩、回报错配 | 场景碎片化、模型被收敛 |

一个跨方向的观察：**三者的瓶颈正在互相转化**。agent 的可靠性瓶颈，靠 infra 的成本下降（更多重试、更多验证调用）缓解；具身的数据瓶颈，靠 infra 的仿真与合成数据缓解；infra 的需求瓶颈，靠 agent 与具身创造新负载缓解。这是一个正反馈，也是一个共同的风险敞口——**任何一环证伪，另外两环都会跟着调整**。

---

## 5. 结论：三条判断

1. **智能体的胜负手是"验证"，不是"智能"。** 模型能力在商品化（Arena 前四名 25 Elo 内），差异会转移到谁能把人工介入率压下来、谁敢按结果收费。
2. **Infra 的稀缺性从芯片转向电力。** 当机柜功率到 200kW，拿电、拿水、拿并网的难度超过拿卡；这会让"有电的地方"重新获得产业话语权。
3. **具身的分水岭是"人类数据"。** Helix 2.5 的 9%→56% 说明预训练数据（人类行为）比遥操作数据更可扩展；谁能规模化获取并治理这类数据，谁就掌握下一阶段。

### 观察指标（建议每季度看一次）

| 方向 | 指标 |
|---|---|
| 智能体 | 真 agent 部署占比、单任务人工介入率、按结果收费的收入占比 |
| AI Infra | 推理占数据中心收入比、单位 token 价格、集群利用率、电力交付周期 |
| 具身 | 年出货量、单台 BOM 成本、无干预连续运行时长、零样本任务成功率 |
