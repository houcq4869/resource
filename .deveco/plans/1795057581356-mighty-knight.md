### 文档结构（两份调研文档一致）

工具定位与背景 → 功能全景（按功能域组织，命令/能力采用上表验证口径）→ 使用要点 → UI 设计（布局、主题、交互特性，为示意图提供素材）→ **信息核验记录**（上表逐项：已证实/来源；笔记原"有误"判断被推翻之处显式说明）。

### Marp 文字稿（3 页）

front-matter：`marp: true`、`theme: default`、`paginate: true`，中文字体栈。每页架构图为主视觉 + 3~5 要点：

- **P1 DevEco CLI**：Mermaid 分层架构图——顶层命令组（15 个，按功能域分组）→ 功能域（项目全生命周期）→ 底层工具链（hvigor/ohpm/hdc/emulator/hilog）；要点突出"为 AI Agent 设计的鸿蒙工具 API"（长选项自描述、JSON 输出、错误即指引）。
- **P2 DevEco Code**：Mermaid 产品架构图——终端 Agent 内核（GLM-5.1 免费通道 + Qwen3.x 视觉验证）→ 扩展机制（Skill/MCP/Plugin/多 Provider，兼容 OpenCode 生态）→ 形态（TUI 主力 + Studio 插件/鸿蒙电脑版）；配 UI 特性要点（39 套主题、暖橙主色 #fab283、4.4s 开场动画、110 列自适应、斜杠命令/@引用/Tab 切模式）。
- **P3 对比总结**：对比表（定位/形态/功能侧重/UI/适用人群）+ Mermaid 定位图（CLI=原子能力层、Code=开箱即用 Agent 外壳、第三方 Agent 经 init --agent 复用 CLI、三者与 Studio 的互补关系）。

每张图旁注明数据来源（哪份调研文档哪一节）。

### PPT 生成工具链

1. `npx -y @mermaid-js/mermaid-cli -i <mmd> -o assets/<name>.svg --scale 2`（首次下载 Chromium 属正常）
2. Marp md 中以 `![w:full](assets/<name>.svg)` 嵌图
3. `npx -y @marp-team/marp-cli slides/deveco-ppt.md --pptx -o ../DevEco-CLI-Code-调研.pptx`
4. 验证 pptx 3 页齐全、中文与架构图渲染正常
