# DevEco CLI & DevEco Code 调研 PPT 制作计划

## Goal

完成"调研 deveco cli 和 deveco code 两个工具的功能与 UI 设计"任务，最终交付：
1. 2 份调研文档（CLI、Code 各一份，Markdown 中文）
2. 1 份 Marp 格式 PPT 文字稿（3 页：CLI 一页、Code 一页、对比总结一页），以架构图为核心呈现
3. 导出的 `.pptx` 文件 + 架构图 SVG 资产

## Scope / Non-goals

**包含**：
- 汇总 `Deveco/` 现有两篇笔记 + WSL 克隆仓库一手材料 + 联网验证补充

- Mermaid 架构图设计与渲染、Marp 排版、pptx 导出

**不包含**：
- 不修改 `Deveco/` 下现有两篇笔记（只在文档中引用并勘误）
- 不做真实 UI 截图采集（UI 以结构示意图呈现，已与用户确认）
- 不克隆新仓库（已有克隆在仓库外，符合 AGENTS.md 约定）

### 三阶段流程

**阶段 1：调研整合（产出 2 份文档）**
- 子任务 A（explore 子代理，只读）：汇总两篇现有笔记要点；尝试读取 WSL 克隆仓库（`wsl ls ~/workspace/repo/deveco-research-20261118/` 或 glob `\\wsl$\**\deveco-research-20261118\**`）中的 README、配置 schema、评测材料；返回结构化素材摘要。
- 子任务 B（联网验证）：web-access skill 抓取官方文档与 gitcode 仓库，逐项核实"待验证清单"；可佐证时本机实查 `devecocli --help`。验证结论统一记录到调研文档附录"信息核验记录"小节（已证实/已修正/无法验证三类）。
- 文档结构（两份一致）：工具定位与背景 → 功能全景（按功能域组织）→ 命令/使用要点 → UI 设计（布局结构、主题系统、交互特性，为示意图提供素材）→ 信息核验记录。

**阶段 2：文字稿（Marp md，3 页）**
- front-matter：`marp: true`、`theme: default`、`paginate: true`，并设置适合中文的字体栈。
- 每页布局原则：架构图占主视觉，配 3~5 条要点，每页总字数克制。
  - **P1 DevEco CLI**：Mermaid 分层架构图——命令组（create/build/run/emulator/device/signature/check/docs…）→ 功能域（项目全生命周期）→ 底层工具链（hvigor/ohpm/hdc/emulator/hilog）；要点突出"Studio 能力命令化"。
  - **P2 DevEco Code**：Mermaid 产品架构图——终端 Agent 内核（GLM-5.1 对话 + Qwen3-VL 视觉验证）→ 扩展机制（Skill/MCP/第三方 Agent 接入/配置三级优先级）→ 与 DevEco Studio 的集成关系；配 UI 特性要点（TUI、主题系统、开场动画等）。
  - **P3 对比总结**：对比表（定位/形态/功能侧重/UI/适用人群）+ Mermaid 定位图（TUI Agent vs IDE 插件、互补关系、选型建议）。
- 文字稿中每张图旁注明数据来源（引自哪份调研文档哪一节），便于追溯。

**阶段 3：PPT 生成（工具链，均为 npx 即用）**
1. `npx -y @mermaid-js/mermaid-cli -i <mmd> -o assets/<name>.svg --scale 2`（首次运行会下载 Chromium，耗时较长属正常）
2. Marp md 中以 `![w:full](assets/<name>.svg)` 嵌图
3. `npx -y @marp-team/marp-cli slides/deveco-ppt.md --pptx -o ../DevEco-CLI-Code-调研.pptx`（pptx 导出为图片模式，同样依赖 Chromium）
4. 验证 pptx 3 页齐全、中文与架构图渲染正常

## Risks And Compatibility

| 风险 | 缓解 |
|---|---|
| WSL 克隆仓库不可访问 | 直接跳过，依赖本地笔记 + 联网，不阻塞 |
| mmdc / marp-cli 需下载 Chromium 失败（网络/代理） | 设置 `HTTPS_PROXY=http://127.0.0.1:7890` 重试；仍失败则降级：交付 md + SVG + HTML 版，并在 README 写明手动导出 pptx 的命令 |
| Clash 代理不可用导致联网验证失败 | 存疑项标注"截至调研日无法在线验证"，PPT 注明调研日期与版本口径 |
| Mermaid 中文渲染字体问题 | mmdc 加 `--theme neutral` 与 fontFamily 配置；SVG 中文字体回退到系统字体 |
| Marp SVG 嵌入在 pptx 导出时不清晰 | 使用 `--scale 2` 高清渲染；必要时改用 PNG 输出 |
