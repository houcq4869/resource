# 00 · 全景图：写给 C/C++ 程序员的 JavaScript

> 你的进度：练习 1（类型坑）已 8/8 通过 ✓ —— 说明你的直觉防线已经建立，这套教程会在此基础上继续加固。
> 本教程为你定制：**该跳过的坚决跳过，该死磕的绝不轻描淡写。**

## 0. 一句话定位

| | C/C++ | JavaScript |
|---|---|---|
| 类型 | 静态，编译期检查 | 动态，运行时才知道 |
| 内存 | 手动 / RAII | GC 自动回收 |
| 并发 | 多线程 + 锁 | 单线程 + 事件循环 |
| 执行 | 编译为机器码 | 解释 + JIT |
| 部署 | 平台相关二进制 | 源码直接分发（Node / 浏览器） |

所以你不是在学"又一门语言"，而是在更换**四套思维模型**：

1. 动态类型的纪律 —— 第一章
2. 闭包 + this —— 第二章
3. 单线程事件循环 —— 第三章（最重要的世界观转换）
4. 模块 + 包管理 —— 第四章

## 1. 你可以直接跳过的

- 运算符与优先级（几乎同 C）
- `if` / `for` / `while` / `switch` / `break` / `continue`（同 C）
- 函数的定义、调用、返回值（同 C，只是不需要声明原型和头文件）
- 位运算（同 C）
- "程序 = 数据 + 逻辑"的一切基本盘

## 2. 你要死磕的（按性价比排序）

1. **异步**（第三章）：单线程并发和多线程是两种世界观，不能靠类比，只能重建
2. **this**（第二章）：运行时绑定 vs 你熟悉的编译期绑定
3. **闭包**（第二章）：JS 没有"栈帧销毁"这回事
4. **类型转换的坑**（第一章）：动态语言的税（你已经交过一次学费了 ✓）
5. **原型**（第二章）：花 20 分钟理解即可，现代代码都写 class

## 3. 学习循环

每个知识点走同样的四步：

```
读教程小节 → 立刻在 REPL 里敲一遍并改着玩 → 做对应练习 → 全过才进下一章
```

REPL 用法：终端输入 `node` 回车，进入交互环境，`Ctrl+D` 退出。比起写 `main.c` 再编译链接，REPL 是 JS 学习的最大红利——**用它**，相当于随身携带的调试器。

另一个趁手工具：`node --watch 01-syntax/02-array-methods.js`——文件一保存自动重跑，适合边写边测。
