| 武器 | 补正 | 武器 | 补正 |
|---|---|---|---|
| 太刀 | 心·武·技 | 薙刀镰 | 体·技·咒 |

- 补正统计：**武 7 种 > 技 6 > 勇 5 > 刚/体 4 > 心 3 > 咒/忍 2**——点 99 武可吃 7 把武器的 A- 级修正。
- **加点路线**：
  - 一周目：先各属性 10（水桶），**忍/咒至少 30**（30 是实用阴阳/忍术的底线）；
  - 阴阳流（当前版本主流）：咒 200 + 体 150（或体 200+咒 150）+ 勇 150 + 刚 100+，武器词条洗"攻击反映（咒）"让咒点一鱼两吃；
  - 洗点用**六道轮回之书**（任务奖励/商店购买，价格翻倍上涨，别乱用）。

## 二、装备基础

### 2.1 稀有度与等级

白→黄→蓝→紫→**绿（神器）**→**橙（神宝，四周目起）**。绿以上有爱用度与恩宠。装备等级上限 **200+120 加值**（+值词条二周目起出现）。**一周目装备等级 >> 词条**：武器保持比掉落高 4-5 级（合魂升级），防具跟等级走。

### 2.2 词条（铭）

- 每件装备词条上限 **7**；分固定词条（六边形容器）与可洗词条。
- **星号词条**（名字前带★）：无法通过重炼获得，最稀有最值钱（星号血量350、星号承伤-5%、星号近攻妖力+18% 等）。
- **继承词条**：爱用度 999 后生效——`>|` 补充词条（给词条不满的装备加一条，极稀有）、`|>|` 移植词条（转移给同部位装备）。神器不可继承给神器以下；同名词条继承无效；部分词条互斥（如吸体与刺击回体）。
- 好的继承词条胚子（挖坟挖到的）留着别分解。

### 2.3 套装与防具

- 防具分轻/中/重（1/2/3 秤砣），重量决定**敏捷**（A-D，影响耗精与闪避）与**坚韧**（防御时精伤减免，A韧最硬）。毕业标准通常 B敏+A韧。
- 套装效果按件数 2-7 件阶梯触发；著名套装：西国无双（雷/虎冲）、阴阳武者（阴阳术向）、大山津见恩宠、祈月斗将等，全表见仁王wiki 防具页。
- **恩宠**：绿装起随机附带的神器恩宠词条，等效一套"隐形套装"（大山津见=减伤硬度、月读=阴阳术增伤、祸津日=妖怪技向）。**最终恩宠只出现在橙装神宝上**，绿装的恩宠只是过渡。恩宠可用合魂继承更换。

## 三、铁匠铺闭环（锻造屋全功能）

| 功能 | 用途 | 要点 |
|---|---|---|
| **锻造** | 造装备/道具 | 素材品质决定成品品质概率（紫装=固有词条+2~4 可洗）；神器锻造需神器碎片×10（概率 80%） |
| **合魂** | 升级装备等级+继承词条+转移恩宠 | 材料+基底都满爱用度时继承词条；武器等级提升最优先 |
| **重炼（转铭）** | 洗可洗词条 | 消耗灵石炭四档：灵石炭→良木→名木→神木（开放更高词条池）；洗一条另一条选项会重置 |
| **改造** | 调整能力值修正 | 漂泊刀匠支线解锁；可选**两种**修正（几乎不会双 A，做取舍） |
| **分解** | 装备→素材 | 紫装=1灵石炭、蓝=3碎片、黄=2碎片；10碎片=1灵石炭，3良木=1名木，3名木=1神木 |
| **买卖** | 赚钱/捡漏 | 低于当前用的品质全卖；可买带好继承词条的武器 |

灵石炭来源：分解 + 逢魔任务（每日刷新，一/二/三周目分别给良木/名木/神木）+ 各周目主线首通。

## 四、Build 流派

### 4.1 强度共识（高周目视角）

- 高周目敌人没有混沌就是刮痧 → **一切毕业流派都围绕"稳定挂双属性混沌"**。
- 绝境流削弱后，**近战阴阳（校服）**是容错率与强度综合最优的毕业方向。
- 武器强度梯队（无脑复读向）：手甲（毕业级，驱钟馗+完美无间）> 双刀（磐石刀，最肉）≈ 薙刀镰（三千风）> 机关棍（龙虎天地对大妖）> 大太刀/大斧/太刀/锁镰/手斧（各吃操作/配装）。

### 4.2 毕业校服：近战阴阳

| 部位 | 配置 |
|---|---|
| 防具 4 件 | 阴阳武者战甲（胸手腰脚） |
| 恩宠 | 5 大山津见 + 2 月读（饰品带"组合效果所需装备数-1"词条） |
| 头 | 怨灵面或酒吞童子面具 |
| 守护灵 | 主**貘**（DLC3 猛/妖，毕业级）副玄武/白泽 |
| 魂核 | 独脚踏鞴（大锤）标配 + 火车 + 牛头/胧车/妖蟹按需 |
| 武家 | 丰臣（回血+25%经验）/ 上杉（最肉）/ 前田（伤害最高） |
| 武器 | 双刀（磐石刀奥义，最稳）或机关棍；词条洗"攻击反映（咒）A-" |
| 阴阳术 | 从雷×2 从水×2（混沌）禁雷 禁水 夺灵 结界 金刚 昂妖 火弹 |
| 忍术 | 替身×4 透波×3 猫步×3 |
| 毕业面板参考 | 血 7500+ / 防 11000+ / 近战攻 6300+ / B敏A韧 / 阴阳术力 500+ |

打法骨架：BUFF 拍满 → 从水从雷挂混沌 → 妖怪技削上限 → 处决循环。

### 4.3 过渡期思路（二~四周目）

- 二周目：防御最高捡着穿，忍术点毒附魔+毒镖，饰品双"对毒敌增伤"，主天眼孔雀副猪竹王，魂核牛头+夜刀神——伤害溢出不卡关。
- 四周目（分水岭，出橙装）：开始定向刷恩宠；武器找魔缘锡杖/鬼猎鬼机关棍或染血双锲，饰品洗"优先掉落武器/防具"，刷齐 月读3+阴阳武者5(+祸津日)。
- 刷宝技巧：饰品重炼出"优先掉落已装备的武器/防具/饰品"词条可定向毕业；**掉落倾向已装备的恩宠**——出了大山件立刻穿上再刷。

### 4.4 词条优先级（防具按部位）

| 部位 | 优先词条 |
|---|---|
| 胸/膝 | ★血量350、★承受伤害-5% |
| 腿 | ★闪避距离延长 |
| 头 | ★近攻妖力+18%、其他伤害/精力星号 |
| 臂 | 近攻精力-8%、一难解除时间延长 |
| 武器 | 近战伤害、武技伤害、攻击反映（主属性）、近距攻击精力 |
| 通用 | 属性伤害、混沌相关；绝境流换绝境系词条 |

## 五、养成支线系统

- **木灵庇护**（神社切换，同时只一种）：精华+25%（巫者）/ 装备+5%（武士）/ 魂核+5%（山伏）/ 仙药+25%（药师）/ 素材+25%（猎人）。按当前目标切换。
- **魑魅**：丢装备换同品质随机物；**未净化魂核**是木灵魂核唯一来源。
- **武家**（隐世茶室，3 章后解锁）：加入武家拿常驻加成+战功升级，丰臣/上杉/前田最热。
- **修行任务**：武道/忍术/阴阳术 初传→中传→奥传，尽早做，送技能点与遗发。
