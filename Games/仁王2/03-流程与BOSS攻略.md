## 四、卡点 BOSS 打法要点（原则向）

**通用框架**：观察红光招式（妖反点）→ 常暗阶段管理（BOSS 空精/计时后开常暗，妖反打空可直接破）→ 混沌增伤 → 空精处决循环。

| BOSS | 要点 |
|---|---|
| 马头鬼（教学） | 练妖反的靶子；红光扑咬慢，猛/幻反都好接 |
| 烟烟罗 | 火属性；烟遁身追着打；常暗中招式变多，留妖力 |
| 夜刀神 | 蛇群召唤优先清；水属性弱点概念：挂雷/净打混沌 |
| 镰鼬 | 三连妖风=最大威胁，绕背输出；**变身后倒地 X 技可用妖怪化冲击波重置** |
| 今川义元 | 人形 BOSS：低精力压制好打；投技距远就闪 |
| 斋藤义龙 | 大剑横扫范围大，中段游走蹭刀 |
| 祟枭 | 飞行态射弱点亮（远程/弓）；落地输出 |
| 真柄直隆 | 大太刀人形，兄弟刀支线里弟弟会乱入（先破坏大水晶可避免） |
| 浅井长政 | 人形高攻；守稳反击流 |
| 牛鬼 | 体型大削精快；注意冲撞红光 |
| 火车 | 火车骨架常暗源头判定特殊；妖反接扑击 |
| 两面宿傩 | 双形态，常暗后激化；范围技多，贴侧后 |
| 柴田胜家 | 挥大锤后摇大，滚后 punish |

## 五、Endgame 一节（压缩版）

- **周目难度**：映于眼瞳通关后逐级解锁更高难度（任务重打、等级上限 200、+值词条、恩宠体系随周目展开）；三部 DLC 各加一档专属难度（修罗/顿悟/仁王的梦路），魂核等级上限随之抬到 190-200。
- **奈落狱**：高周目解锁，**108 层**随机走廊，每层出怪与 BOSS 随机；通关掉**冥府琉璃**（加点规则：每次挑当前代价最低的项目点，性价比最优）。
- **深处**：奈落狱之下的 **30 层**，需要**绘卷**进入（常世同行刷"咒勇绘卷"，洗出体之深奥/地狱道的指引/妖念量表词条）；毕业刷法：深处掉落倾向**已装备恩宠**——先凑 1 件大山，穿上去刷第 6 层小怪滚雪球到 6 大山。
- **地狱雅士**（旭光篇支线）：四周目起的定向刷宝圣地（橙武/恩宠）。
- **常世同行/薄云**：联机共斗玩法，绘卷与绘卷词条的主要来源。

## 六、全收集速记

- 木灵 225（本体 150 + DLC 各 25）：庇护加成看总数，收集度即战力。
- 温泉、隐藏道具每章节约 5 个；DLC 各 5 个隐藏道具。
- 西行的歌牌（DLC1）、茶器（松永久秀）、平蜘蛛碎片（蜘蛛粉碎）等分支收集影响支线结局与奖励。
